AnywidgetInstruments

Instrument widgets for computational notebooks and dashboards, built on anywidget. The front end is the implementation; Python, Julia and Grafana are hosts that set its traits.

  • anywidget-instruments

    The core of the family: base widget view and Python class, trait contract and its generator, themes, kernel liveness.

    Repository

  • anywidget-instruments-industrial

    Instrumentation widgets: gauges, tanks, LEDs, switches, charts, alarms, SCADA objects.

    DocumentationRepository

  • anywidget-instruments-automotive

    Automotive instruments: speedometer, tachometer, gauges, tell-tales, trip computer, cluster. For visualization only: no widget is meant to be operated while driving.

    DocumentationRepository

  • afm-host-panel

    Grafana panel plugin that runs anywidget front-end modules, with both widget libraries built in.

    DocumentationRepository

  • Anywidget.jl and AnywidgetInstruments.jl

    Julia host for anywidget front-end modules, and the instrument widgets in Julia.

    Anywidget.jlAnywidgetInstruments.jl

These widgets are for visualization, teaching, simulation and supervision. They are not safety-related systems.
